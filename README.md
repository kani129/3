## 📖 Concept Sheet

### 🏥 鍼灸サイトリニューアル

| 項目 | 内容 |
|:---|:---|
| **プロジェクト名** | 鍼灸サイト リニューアル |
| **ターゲット** | 20〜40代を中心とした女性。自律神経の不調に悩む方や、美容・健康に関心のある女性。 |
| **GOAL** | 新規顧客の獲得と、地域の方への認知度向上。 |
| **デザインコンセプト** | 「シンプル・やさしい・清潔感」をテーマに、初めて訪れる方でも安心感を持てるデザインを目指しました。 |
| **カラーテーマ** | 木のぬくもりを感じるナチュラルなブラウンをベースに、やさしく落ち着いた配色で統一しました。 |
| **フォント** | 見出しは明朝体、本文はゴシック体を使用し、メリハリのある読みやすいデザインにしました。 |
| **ユーザーシナリオ** | 身体の不調に悩む女性が、「ここなら相談しやすそう」と安心して来院を検討できることを意識しました。また、美容鍼に興味がある方や、鍼・お灸に初めて触れる方でも不安を感じず、気軽に予約したいと思えるような、やさしく親しみやすい雰囲気を目指して制作しました。 |
